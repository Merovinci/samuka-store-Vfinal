# Logos das marcas (faixa rotativa do rodapé)

Salve os arquivos aqui seguindo o padrão (nome = slug da marca em `src/data/brands.js`):

```
public/images/brands/alexander-mcqueen.png
public/images/brands/amiri.png
public/images/brands/armani.png
public/images/brands/asics.png
public/images/brands/balmain.png
public/images/brands/brooksfield.png
public/images/brands/burberry.png
public/images/brands/calvin-klein.png
public/images/brands/casablanca.png
public/images/brands/diesel.png
public/images/brands/fred-perry.png
public/images/brands/gucci.png
public/images/brands/hermes.png
public/images/brands/hugo-boss.png
```

Recomendado: PNG com fundo transparente (a faixa rola sobre fundo escuro,
então logo com fundo branco sólido vai aparecer com uma caixa branca atrás).
Altura ideal: ~64-96px, largura livre — o CSS já ajusta a altura sozinho.

Enquanto o arquivo de uma marca não existir, aparece o nome dela em texto
no lugar — nada quebra.
